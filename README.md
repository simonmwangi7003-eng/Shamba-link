# ShambaConnect

A premium Kenyan farm-to-market marketplace demo built with vanilla HTML, CSS, and JavaScript.

## Run locally

Open [index.html](./index.html) directly in a browser, or serve the project from a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Responsive landing page for buyers and farmers
- Product marketplace with search, filters, sorting, and pagination simulation
- Shopping cart and inventory validation using LocalStorage
- Demo M-Pesa checkout workflow for Kenyan mobile numbers
- Role-based buyer, farmer, and administrator dashboard previews
- Farmer listing form with realistic Kenyan produce data
- Platform messaging, orders, and order status concepts for a later backend integration

This is a front-end demo and does not process real M-Pesa or financial transactions.
